Privacy policy

Protadium · last updated 23 November 2026

Protadium is a personal tool. Its only user is its owner, who also owns the Google account it signs in to.

Data it uses

Protadium asks Google for the drive.file scope only. With it, Protadium uploads the owner's own video files and their text notes into a folder it creates in the owner's Google Drive. It cannot access any other file.

Where the data goes

The sign-in token is stored only on the owner's own computer. Uploaded files go only to the owner's own Google Drive. Protadium does not send Google user data to anyone else, does not sell or share it, does not use it for advertising, and does not use it to train AI or machine-learning models.

Keeping and deleting

Files stay in the owner's Drive until the owner deletes them. Access can be removed at any time at myaccount.google.com/permissions, which makes the stored token stop working.

Google API Services User Data Policy

Protadium's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
